# Internship Records API

A beginner-friendly REST API built using Node.js, Express.js, and SQLite.

This project provides CRUD operations for internship records with input validation, pagination, consistent API responses, seed data, and SQLite persistence.

## Tech Stack

- Node.js
- Express.js
- SQLite
- CORS
- REST API

## Features

- Create internship
- Get all internships
- Get internship by ID
- Update internship
- Delete internship
- Input validation
- Pagination
- SQLite database persistence
- Seed data
- Consistent JSON responses
- Proper HTTP status codes
